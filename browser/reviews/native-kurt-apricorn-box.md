# Kurt's saved Apricorn queries

This patch follows `0389f9a6`. It supports the separate saved Apricorn inventory and four existing native query commands, allowing the actual forced empty-box Kurt scene after Proton to finish. It does not implement the Apricorn selection overlay, tree animation/harvest admission, day rollover/crafting schedule, Aprijuice or rendered campaign traversal.

Native `SaveApricornBox` stores seven color counts, a Kurt quantity and color (`include/apricorn_internal.h`). `InitApricornBox` zeroes the save (`src/apricorn_box.c:84`). Counts are zero-based0–6, whereas tree `APRICORN_*` constants are one-based1–7. The `gApricornBallItems` table is Level/Moon/Lure/Friend/Love/Fast/Heavy. A stored color≥7 returns a Poké Ball in the native getter. A zeroed box therefore returns Level Ball for GetKurtBall even with no active job; it is not arbitrarily mapped to the initial scene reward.

`State.apricornBox` is optional for v2 saves. Queries interpret absence as the source's zeroed initial storage without mutating or creating a job. Populated storage is read, never ignored or inferred from Bag. Legal game-produced counts and Kurt quantities are integers0–99; malformed browser arrays, holes, fractions, negatives and overflowing counts reject before mutation. Stored color permits the native u8 range0–255, retaining its≥7 fallback. This is validation of legal browser save values, not emulation of every corrupted native save byte pattern.

The adapter exposes Count/Total/Give/Take/SetKurt/GetQuantity/GetBall/Clear primitives. Low-level Give saturates at99; the native tree command's separate preflight rejects overflow atomically. Taking insufficient stock leaves it unchanged. Assigning Kurt takes the selected stock once, and clearing uses SetKurt(0,0), without refunding or deleting other colors. No quantity is fabricated because the selection UI is missing.

`GetKurtApricornQuantity`, `GetTotalApricornCount`, `GetKurtBall` and `ClearKurtApricorn` now use that storage in ScriptVM. Actual Kurt005 gives item492, which is **Fast Ball** (the earlier critical-path note mistakenly called492 Lure Ball; Lure Ball is494). It enters the empty-box query path, advances VAR_UNK_4080 to4 and completes native Kurt phone registration. A repeated ordinary conversation gives no duplicate scene reward. Waiting populated jobs retain their full counts; completed jobs return the original color's Ball/count and clear. Nonempty free stock reaches explicit `LaunchApricornBoxForKurt` unsupported behavior rather than being disguised as empty.

58 affected tests pass, including10 Apricorn fixtures, the original first-badge/Egg branches, source recovery, native coordinate aliases and Warp ABI. The production `SourceActionRecovery` is exercised after actual Kurt script collection has changed Bag, cleared its job and advanced vars: a failing receipt restores the whole saved state in place. TypeScript passes. Native source/adapter/test hashes and log hashes are in `native-kurt-apricorn-box.json`. No main/UI/World/terrain/music edits, build or browser run are included. The helper and Warp commits still need parent host wiring/release; Azalea's gym and field Cut remain separate blockers. Total parity remains partial.
