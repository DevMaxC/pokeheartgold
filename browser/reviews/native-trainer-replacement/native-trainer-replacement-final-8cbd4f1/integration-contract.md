# Native trainer replacement helper integration contract

Base d0900800545927c135760296ab0ee18df7f0c8f6; only two new files, no Battle/math/main/types edits. Runtime SHA 10aba7042db71a4f97c70b358d90abb20f70db05a40f198afe480e2e8deb16c1 is currently frozen pending actual Opus review.

1. Call nativeTrainerReplacement(data,context,evaluator) only for ordinary trainer singles after selecting the native current opposing battler (singles has no RNG). It returns a zero-based party index; native controller reply is index+1. Check bounds before sendout: on an empty remaining party the literal task fallback returns party.length, not necessarily6.
2. Context.party contains native PARTY metadata: species, isEgg, HP, native duplicated type slots (mono-types repeat), numeric ability and held effect, original four move IDs (zeros fill absent entries). PP is deliberately irrelevant. IVs in HP/Atk/Def/Speed/SpAtk/SpDef order and naturalGiftType are required only for the respective dynamic move. Do not infer candidate types from transformed live battler types.
3. Supply actual active selected party index. AI preselection (default6) is honored immediately, before any evaluation; native singles partner aliases this actor; the optional partner fields default6 as redundant-exclusion sentinels. Never use this helper as a player-party chooser; native task fallback checks only HP/selected slots, so valid nonempty/nonEgg trainer party data is a precondition.
4. Opponent metadata is the current active target types/ability/held effect. Supply exact field gravity, active weather flags (rain/sand/sun/hail source precedence), live weather suppression, and charge-move-hit bit if relevant. Undefined native WeatherBall/no-weather/suppressed local is an explicit unsupported branch, not guessed Normal. Ordinary type override0 is a sentinel meaning use base move data, not explicit Normal.
5. Evaluator.currentActorDamage(moveID) calls native noncritical maximum-roll CalcMoveDamage with the CURRENT/just-fainted outgoing trainer actor, NOT the candidate: current level, stats, stages, status, ability, item, field/screens. It returns the integer BEFORE native STAB/type application. The leaf truncates this assignment to u8.
6. Evaluator.applyCurrentActorType(moveID, candidateMoveTypeOverride, scoreU8) then applies native STAB/type/item/ability using that SAME outgoing actor; it receives the already-truncated byte. Return {damage,immune}; leaf truncates a SECOND time before immunity clears score. Do not combine both callbacks into one float/formula and truncate only at the end. Do not consume critical/random-range draws. Status moves with power0 still evaluate; empty/power1 slots skip both calls and reuse the prior score, including the last Stage1 score.
7. Source Stage1 uses candidate ability for its flag-only check, not the outgoing actor. Stage1 offensive type scores also count a mono-own type twice and wrap u8. Flags are ordered table operations rather than net-effectiveness: SE may coexist with immunity and still satisfy the native Stage1 test.
8. Actual trainer21 Scyther explicitly selects ability SECOND, personal [Swarm,Technician], hence Technician101. Sitrus uses holdEffect13 HP_PCT_RESTORE25. The engine adapter must support required ordinary native modifiers or explicitly reject them; the helper does not implement damage or new combat effects.

Evidence: 9 focused tests compare actual extracted C selector/task/type/move-type/flag/charge helpers, all5832 type-score tuples and1440 independent flag contexts. Arithmetic/controller controls use neutral snapshots; actual Bugsy team metadata comes from source. Heavy damage calls are deliberate neutral ports in these leaf tests; full live engine damage/order proof belongs to the engine integration tests. No broad battle/progression approval.
