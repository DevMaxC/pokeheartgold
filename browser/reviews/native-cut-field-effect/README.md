Source PlayCryEx pattern0 does not act on PlayCry's success result; `ScrNative_WaitCry` completes when actual playing count is zero. Browser fetch/hash/decode/context-suspension/start/playback failures therefore report `failed-admission`/`failed-playback` through REQUIRED `onStatus` and allow actual visual/script progress.
