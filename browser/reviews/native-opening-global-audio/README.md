# Native opening and global audio controls

Runtime is pinned to `2f37f47d5595b7e9198b7b0fce28b96577ef94b9`, following initial opening patch `842e8678`. The only Main change is its OpeningView constructor argument: a live preference closure borrowing the existing gesture-unlocked audio output. The preceding native Main and campaign reviews retain their own exact source scope.

The original Marill cry used a separate HTMLAudio element and bypassed the new global mute, volume and background-page gate. Opening cries now borrow the single shared master output, own their pending I/O and nodes, and cancel them when the opening or player is disposed. Muted-at-call requests fetch nothing. A cry still muted at load completion is discarded; mute followed by unmute before completion uses the current enabled output. Asset preparation is asynchronous and can delay a cry up to four seconds; no native timing equivalence or historical mute latch is claimed. No context is created, resumed or unlocked by this helper.

Native opening choices now leave Enter/Space/F on the global audio button to that control. The dormant legacy opening title gets the same guard. The immutable d8 audit distinguishes the active Marill183 path from dormant Ho-Oh250/title and independent hatch fallbacks; current Main injects its shared Togepi cry port.
