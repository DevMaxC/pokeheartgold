# Native Azalea battle volatile contract — partial pure layer

This layer defines source-backed scalar operations and lifecycle boundaries for seven moves selected by the actual upcoming trainer teams. It does not edit `Battle`, its math, admission list, UI or World. All seven effects remain Unsupported. Tests build the actual imported Proton/Bugsy/rival teams, but do not execute complete natural battles or inject a victory. A successful primitive test cannot establish that those campaign battles are playable.

`native-azalea-volatile-contract.json` pins35 full native C/subscript/data files. Native `effect_script_0047/0049/0065/0100/0106/0109/0228` and their complete downstream subscripts were read with the controller/command/util context. Upcoming Proton486 has Supersonic; Bugsy21 has Focus Energy/U-turn; the Azalea rival variants266/269/1 have Supersonic/Spite/Mean Look/Curse, with Reflect on Bayleef in variant1. These are selected-move risks, not proof that every possible winning strategy must select them.

The proposed active-battler state is `{status2,meanLookSource,previousMove}`; Reflect belongs to the side. These are ephemeral, separate from saved Pokémon. The host must bind each battler slot to the correct active Mon and update both sides when switching or fainting. It must preserve native before-turn Rage masking: when a raging battler selects a non-Rage move, `status2 &= STATUS2_RAGE` clears its other flags before either action. The existing engine only models some flags, so adding one flag without expanding that mask would be incorrect.

Raw-u16 RNG callbacks make the scoped modulo/low-bit operations and branch draw counts reviewable. They do not provide global battle RNG parity, a seed/stream implementation or a mapping from every existing engine float draw. Ability/item/type flags accepted by a pure function must come from actual battle context; immutable personal species types alone cannot stand in for Roost, suppressed abilities or future Transform. Current Gen IV species/abilities and held items such as Own Tempo, Mold Breaker, Magic Guard, armor, Sniper, Light Clay and Shed Shell are real data cases, not hypothetical future generations. Transform, Baton Pass, double battle control and unported reactions stay explicit Unsupported requirements where encountered.

Initial9 primitive/source-fixture tests and TypeScript pass. No engine effect was enabled, no battle victory was supplied, and no build/browser/full suite was run. An actual read-only Opus review will be recorded separately; the earlier gym or Apricorn reviews do not cover this new layer. Parent integration must add real selected-move/action-order/RNG/lifecycle tests and actual native trainer battles before advancing campaign parity.
