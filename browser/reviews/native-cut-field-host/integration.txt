Native Cut field host + shared field clock integration contract (provisional, not attached to main)

Dependencies: Native 0d6ddf9c0cb1bc0bc181abf1ea7e68c25bf4db7b; reviewed original Cut commits 4d5431e0,0d509f9e,9a46fed2,b8801e8d cherry-picked separately. This leaf changes only World minimal hooks and adds native-field-clock.ts/tests, cut-field-host.ts/tests. No main/VM/UI/music-player changes.

Install once for actual loaded field lifetime:
  const clock = new NativeFieldClock({
    field: () => ({map:world.fieldMapID,mapRunning:started && world.fieldMapRunning}),
    onError: scopedDiagnosticSink
  });
  clock.attach(world);
World.draw synchronously calls frame(dt) before transition/battle/Egg early returns. No extra RAF/timer or camera branch. Main owns actual `started`/field-parent admission; UI.busy or VM.busy do not mean native field-map stopped. World guards transition, battle overlay and camera-owning hatch presentation. Native background streaming `loading` is unrelated.

Clock API:
  createScope(map, ownerSignal) -> NativeFieldTaskScope
  scope: map, signal, active, tick, phase, waitFrames(n, signal?), dispatch(asyncWork, signal?), onTick(syncCallback), cancel(reason?)
  clock: tick, phase, frame(dt), settled(), cancel(reason?), dispose(), failure
`dispatch` starts during next admitted scripts phase; `waitFrames` releases there. Runnable Promise continuations drain through one REAL MessageChannel task before queue callbacks. External IO/UI still pending does not become source-equivalent native work. Task callbacks are synchronous opaque controller blocks in stable registration order, not a general DS SysTask priority/insertion emulator. New task-phase registrations reject. At most one native tick per draw, no overlapping async phase or catch-up bursts; stalls slow native execution. Persistent phase/tick is not reset for a new Cut/action or map. Actual transition cancels all scopes; owner abort/scope.cancel cancels only that scope. A rejected dispatch alone does NOT drain non-cooperative underlying work; controller must abort and await its owned work before rollback.

Azalea: one map180 scope owns static updates; separate scopes own action ticks. It consumes this driver; no second World slot/clock. host.leave before real map transition may restore original view while old map is present, then World transition synchronously cancels all scopes.

The shared music player supplies the EXISTING unlocked Context/master gain/lifetime; never new Context/resume/BGM ownership. Effect templates/resources remain caller-owned. Host owns effect clones/voices only. Host.dispose does not dispose shared clock or native templates.

Host.run(originMap,actionSignal,()=>actualVM.run(...)) MUST be inside outer SourceActionRecovery. It preflights actual Cut SE before dispatch, owns actor/effect/source completion and drains before rejection/rollback. Root saves only after complete presentation/transaction. Native script HidePerson owns tree visibility/flag; host never removes the tree. Ordinary transitions when no Cut is owned must not cancel an unrelated VM.

Required unresolved actor/UI ports (no substitutes in this leaf):
- cutIn(slot,context,scope): actual original kind0 native banner SYS-TASK completion (done flag). The host then exposes completion at the next source script poll; reviewed VM supplies its separate bytecode resume tick, so source StartFX is done+2. Do not add another native-script poll inside the actor port. Original resource/presentation must be exported/implemented; immediate or synthetic banner is NOT accepted.
- swap(mode1|2,context,scope): native player/follower TaskManager FSM, logical map coordinates/baseY, actual movement/turn completion, source parent resumes at child completion.
- jump(count,context,scope): actual native follower hop state machine (including source first hop for count0); Diglett/Dugtrio skip is source-backed here.
- reset(context): source synchronous FollowPlayerMovement_Reset.
- snapshot(): logical player/follower tile, exact ground/baseY, registered actual State party mon, native follower visibleFlag. Do not use rendered/hopping/interpolated coordinates or sprite visibility. FollowMonIsInactiveOrVisible is not plain followerActive.
- cancelScript(reason): cancel the OWNED VM and signal/cancel only its owned UI message/choice waits, so their Promises drain. Blanket ui.close could clobber another owner and is not accepted. Every async actor adapter honors context.signal and drains its writes/resources before rejecting; it consumes scope phase/waits rather than per-effect timers. Field-map/State replacement cancels and rolls back.
