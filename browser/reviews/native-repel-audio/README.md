This leaf exports original Repel sounds SELECT1500 and CARD21535, their finite WebAudio transport, and a source-backed root-owned PLAYER4 registry. It is based on accepted Azalea audio93acce92 solely to reuse its unchanged shared PLAYER3. It changes no Main, VM, World, Bag, audio clock or existing Azalea helper. Host integration and complete native sound-engine parity are not supplied.

The native player distinction is essential. SELECT uses PLAYER4/bank700/volume54/channelPriority104/playerPriority64. CARD2 uses PLAYER3/bank700/volume110/channelPriority104/playerPriority64. Both native players have maxSequences1/heap2000. SELECT allocates a separate sequence-player slot; its allocation does not preempt the CARD2/Cut/Azalea PLAYER3 slot. Both native players share hardware channelMask0xD800, so this does not claim independent hardware-channel mixing or cross-player channel-steal parity. The manifest contains the original695 PLAYER3 and208 PLAYER4 records and both source player records. Channel priority104 is not player priority64. Sequence volume is already rendered; the transport never multiplies it again.

The two WAVs are rendered from the original SDAT SSEQ/sample events, not synthesized tones. SELECT has25776 frames, CARD2 has22362, both stereo32768Hz PCM16, finite/no loop. The exporter pins DualRip80f878b0ebf100f391028bcef69f7c5743473770, ndspy4.2.0/numpy2.2.6 and relevant renderer/source hashes. Independent raw SYMB/INFO/FAT parsing, event-payload equality, source bank/wave hashes, WAV/PCM checks and normal/optimized byte-identical re-export are tested. SELECT's two native SweepPitch events are supported by the pinned sequencer/channel implementation. This is an original SSEQ emulator render, not DS hardware/DAC/global16-channel mixing or browser audition.

Integration contract:

1. Load loadNativeRepelAudio(signal) under root ownership. Its generated manifest SHA pins source/configuration. Unknown/malformed metadata, mismatched WAV checksum/timing or unsupported cue fails explicitly. The metadata loader creates no Context. Preparation borrows only the existing gesture-unlocked music.sharedAudioOutput() and respects its root lifetime. It never creates/resumes a Context, touches master gain, connects to context.destination, owns an independent timer clock or closes shared nodes.
2. Reuse the EXACT NativeSEPlayer3 returned by AzaleaFieldSound.preparePlayer(signal). Construct ONE NativeSEPlayer4(resources,music.lifetimeSignal) at root scope, with the same lifetime signal. Both registries must be shared by every actual caller of those source players, before voices start. The transport validates CARD2 against the existing PLAYER3 metadata; it does not modify Azalea resources or validators. Lower priority rejects, equal replaces, native allocation precedes technical start failure, owner-only cancellation cannot stop a replacement from another transport.
3. Root binds player4.soundUpdate() once to the SAME accepted global after-task/native SoundUpdate phase, alongside the existing PLAYER3 hook. No mapRunning condition, new frame loop or setInterval. A physical finite onended marks browser transport completion; the registry remains counted until this source update. Exact native natural-end count timing is unverified: native NNSi_SndPlayerMain uses ARM7 SND_GetPlayerStatus, whose driver implementation is absent here. The pinned renderer reports SELECT track-end at sample6145 versus its rendered release-tail end25776, and CARD2 track-end12120 versus release-tail end22362. Neither track-end nor WAV length alone proves that native player-status boundary. This leaf uses finite PCM completion and does not claim native WaitSE natural-end timing parity. fade1 likewise remains counted at priority0 until that update. Every VM WaitSE poll must read isPlayerIdle(id) at its actual scripts-phase poll. waitIdle is only a cancellation/convenience Promise and can latch a brief idle interval before an unrelated sequence starts; it is not a replacement for live WaitSE polling.
4. createNativeRepelAudio(resources,{player3,player4,output,report,...}) supplies prepare(signal), play(id,actionOwner,signal,{selectMuted}), isPlayerIdle/waitIdle, cancelOwner and dispose, with failure exposed for asynchronous status callback errors. Both original WAVs prepare before dispatch. Native PlaySE callers ignore voice/no-voice, so browser technical decoder/device/start failures report explicit no-voice and may be retried; they do not invent silence duration or delay. Missing source/configuration/preparation is a thrown unsupported error, distinct from technical no-voice. Host must observe failure and keep its action checkpoint through required presentation.
5. selectMuted is the explicit NATIVE Sound_IsSelectSEMuted flag (sound attr56), not browser master mute or volume0. Original PlaySEEx suppresses SELECT1500/1501 BEFORE allocation when that flag is set; CARD2 remains eligible. The ordinary field starts with native default0; unrepresented link-battle flows must not be silently treated as represented. This adapter requires the boolean; it never derives it from preferences or saved music bits. Master mute/hidden gain remains the existing shared output: a voice can complete while inaudible.
6. Each transport uses private per-voice registry tokens under the caller action owner. One action can own both source players simultaneously. Late old aborts/replays and adapter disposal cannot stop a sibling replacement, external Cut/Azalea sequence or the shared registry itself. Root output abort or Context suspension drains owned nodes. The adapter never disposes either injected player; root owns global disposal. Borrowed output identity/lifetime must stay stable.
7. Future Repel Bag host starts CARD2 at the native counter-assigned/before-used-message phase. Actual std2022 starts SELECT then Lock/message65/ack, without waiting for SE completion. This leaf does not add those hooks, preload messages, decrement field counters, suppress encounters or change ScriptVM's current presentation no-op set. Those actual host bindings require separate source/recovery/audio-phase review before claiming usable Repel.
