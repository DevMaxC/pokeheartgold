# Native tree candidate

Candidate only. The actual browser automation host is disconnected. These receipts establish native-source geometry, pixel, ownership and CPU test behavior; they do not establish browser/GPU performance or final visual approval.

The previous renderer sent DataTexture images through canvas drawImage, caught the failure and selected a plain olive fallback. It also used smooth lobes and left some split/repeated source cards visible. The candidate reads typed native RGBA directly, checks browser-image readiness, and retains the source when pixels are unavailable.

Ordinary parallel tree cards use a closed twelve-sided canopy joined from native alpha row widths at three-source-pixel intervals. Every surface uses actual selected native RGB rows. Used atlas regions and literal full UV bases control width/height; native ground-marker tiles authorize repeated forest fragment removal. Authored native multipart 3D assemblies remain intact.

Proven paired palm crown/stump cards use closed drooping fronds with the literal alpha negative spaces and painted RGBA, a short root patch whose height is the actual vertical UV basis, and a measured native bark shaft. Both cards are removed together only after the replacement succeeds. Top/bottom rays, every selected alpha pixel, exact Float32 edge intervals, actual root/shaft/crown contact and placed transforms are tested.

60 focused tests and TypeScript pass. The native runtime replay covers all124 metadata families in42 actual assets and all80 PNG variants, with unchanged source geometry/materials/maps and no remaining tree/stump card fragments. Native 88 multipart trees remain original. The maximum sampled generated-tree cost is261,600 triangles in land356-93, including277 distinct roots; ordinary NewBark208 is110,592 triangles for256 roots and4 draws. These are deterministic geometry counts, not a GPU benchmark. Full per-family and old/candidate figures are in the JSON receipts.

The software sheet contains actual emitted candidate positions, UVs and native textures from five source families, using unlit orthographic CPU rasterization. It records the chosen direction only. It is not a browser screenshot or a blanket all-family aesthetic pass. No source PNG artwork was edited.
