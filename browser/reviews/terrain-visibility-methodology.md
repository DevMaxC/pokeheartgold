# Terrain visibility audit

Run from the repository root with Node 22 or newer:

```sh
node --experimental-transform-types browser/scripts/audit_terrain_visibility.ts --self-test
node --experimental-transform-types browser/scripts/audit_terrain_visibility.ts --inventory-only --output=/tmp/terrain-inventory.json
node --experimental-transform-types browser/scripts/audit_terrain_visibility.ts --candidate --no-camera --gate=regression --output=/tmp/terrain-all.json
node --experimental-transform-types browser/scripts/audit_terrain_visibility.ts --candidate '--cells=0:21,10' --player-maps=60 --dry-camera --gate=closed --output=/tmp/new-bark-terrain.json
```

The inventory includes every non-interior/non-invalid native map cell, including header-zero background scenery. Headerless rooms sharing a matrix retain separate contexts. It records actual asset bytes, placement, altitude, map type, movement plates, classified material names, opaque terrain footprint, mixed-alpha regions and unsupported evidence. Inventory-only mode establishes no enclosure or visibility coverage.

Expected sides begin with actual positive-Y opaque terrain triangles after terrace deformation. Collinear edges are split before cancellation, so unequal subdivisions and T junctions do not create invented boundaries. OPAQUE materials follow the renderer's alpha contract; MASK/BLEND used UVs are clipped to decoded PNG texel rectangles. Texture indices, repeat/clamp addressing and exact alpha samples are retained. Neither a convex hull nor a terrain bounding box establishes a solid region. Expectations are collected before the historical forest foundation, generated source skirts, new terrain closure and props; physical source/baseline/candidate arrays are frozen before camera searches append props.

A side needs an adjacent native lower movement plate. Propagating a lower support onto another boundary additionally requires a fully blocked, inverse-deformed flat cap and a matching own plate. The conservative highest proven lower support is recorded with its actual source coordinate. Unknown map edges, ambiguous overlapping upper/lower plates, cave/underground volumes and possible lower passages remain explicit unsupported classifications. Adjacent plates reaching the cap height are classified as not establishing an exposed side, rather than silently disappearing from the report.

Every eligible side is tested at three edge positions and three height fractions. Positive-Y opaque existing tops also receive vertical and four raking rays; `--top-stride=2` is the default spatial sampling stride. A completely missing horizontal top can be inferred only from literal native geological wall-rim loops, simple nonintersecting contours and continuous matching movement-plate coverage. Nested loops remain holes. Source entrances, lower passable floors and cave/underground contexts prevent automatic roof inference. The synthetic concave missing-cap, unmatched-plate, source-entrance, lower-passage and nested-hole fixtures verify these guards. Native decorative post rims lacking matching plates remain unsupported, not inferred roofs.

Physical and exterior render-side coverage are separate. The shared-edge ray/triangle projection is watertight without epsilon or numerical edge allowances. Side rays cross a 0.16-tile band; top rays cross the expected surface vertically and obliquely. The original native source is deformed with the same terraces before comparison. Historical rendered baseline and candidate use the same placed neighboring terrain. Context chunks retain full exact rays, actual blocker triangles, material/mesh identity and native support evidence. Short-band misses on an arbitrary sloping or recessed form are not, by themselves, whole-volume holes.

Opening-preservation tests are independent of skipped solid-volume expectations. They inspect actual centred source warps and indexed entrances, body-width approaches and full-tile headroom samples, source-clear lower passable channels including Surf, and nested native rim holes. A source-clear bounded opening must not acquire a blocker from candidate-generated terrain. An actual native warp or indexed entrance additionally establishes functional entry authority within its measured one-tile bounds, even when original door or cave artwork blocks the source ray. Ordinary speculative passages still require a clear source ray. Body and headroom checks catch both a new wall across a passage and a new roof over an entry or inner hole. The Surf, opaque functional door, warp-corner sliver and nested-hole negative fixtures must reject a deliberately inserted blocking mesh.

Camera witnesses start in native warp/Fly/blackout-seeded, four-connected permission components with Surf permitted. This is a geometric over-approximation; ledge direction, HM/story availability and actor state are not certified. Ambiguous multiheight camera floors are excluded, and sampled standing positions are checked against actual furniture. Positions default to a four-tile stride. The search considers nearby streamed cells, eight position sectors, sampled yaw offsets, the runtime 52-degree perspective, pitches 0.18/0.4/0.65/0.95 and desired distances 5/13/28. It applies runtime camera collision shortening, exterior orientation, frustum and actual static geometry/material-alpha occlusion. A one-tile continuation past the expected surface distinguishes a visible hole from an inset opaque skin. Terrain, repaired tree volumes and native props/building closures are included; actors and animated grass are temporary occluders. Finite failure to find a witness is not proof of invisibility.

`--matrices=0,67` and `--cells=0:21,10;0:22,11` restrict context selection. `--player-maps=60` restricts witnesses to New Bark; `--dry-camera` excludes Surf positions. `--max-view-probes=8`, `--max-witnesses=2`, `--camera-stride=4`, `--hole-depth=1` and `--aspect=1.5` make finite budgets explicit. `--no-camera` establishes no player-visibility assertion.

`--gate=regression` requires the candidate and exits with status 2 if a previously solid physical/render-side sample becomes missing, candidate terrain blocks a proven opening, or sampled player cameras expose a remaining hole. `--gate=closed` additionally rejects every remaining expected candidate surface miss. Every mode rejects unreadable actual geometry/material contexts, incomplete selections and changed source/native inputs. Bare or invalid gate values are errors. `--fail-unsupported` also rejects unsupported classifications. Gate success applies only to measured selected surfaces/openings; `coverageComplete` and unsupported counts are separate, and a scoped regression pass is not whole-volume or all-game approval.

Each completed context is atomically written to a separate compressed `.json.gz` chunk with a SHA-256 receipt. The compact master report references those chunks and contains counts, witnesses and unsupported summaries. The adjacent `.chunks/manifest.json` is updated after every context, so an interrupted scan preserves completed evidence without retaining every probe in memory. Prepared cell geometry has a bounded LRU of 24 cells for geometry/inventory scans and 32 for camera scans, enough to retain an actual 25-cell streamed camera window without repeatedly evicting it. This changes caching only, with the same surface/opening/camera samples. Use `gzip -dc path/to/context-file.json.gz` to inspect full rays. To resume, repeat the exact original sampling/selection flags and output path with `--resume`. `--checkpoint-dir=/path` can select a different checkpoint directory.

A resume is accepted only when the complete audit/runtime source hash graph, selection, sampling configuration, all previously used native GLB/PNG/JSON bytes and every compressed chunk SHA match. The graph includes the entire nested application source tree, package manifests/lock, and the actual installed Three.js implementation with its recursive relative imports. Static camera occluders run through the game's current `closeBuildingExterior` dispatcher followed by terrain footings after native placement and terrace offsets. Changed inputs or code reject reuse. A source change during a run invalidates its checkpoint and stops further contexts. Final reports hash all source and native inputs again; an unchanged reviewed graph and independent actual-render visual pass are required before treating evidence as release approval. No finite audit here proves continuous all-angle geological enclosure.
